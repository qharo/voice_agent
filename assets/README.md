# assets

This folder holds the media referenced by the landing page `index.html`.
Drop the finished files here (do not rename):

- `grafana.png` — screenshot of the "Voice Agent" Grafana dashboard with real metrics.
- `demo.mp4` — short screen recording of the UI in action (green-to-black transition,
  someone speaking, the response appearing and playing back). `poster` falls back to the
  green idle screen via the animated CSS mock if the file is absent.

Until these files exist, the landing page renders labelled placeholders.
