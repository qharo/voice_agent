voice_agent

A voice agent on Kubernetes — speech to text, LLM with tool use, text to speech — streamed end to end over a single WebSocket.

GitHub repo ↗ Live demo ↗

This project is a complete voice assistant built and deployed end to end. Hold space and talk; it transcribes live, answers with a tool-using LLM, and speaks back — a full turn in well under two seconds. The browser, the FastAPI backend, and the Kubernetes deployment that ships it are all in this repo.

Highlights

A few things it does

🎙️

Live streaming STT

Moonshine (tiny, quantised) runs on the box and emits partial transcriptions as you speak.

🧰

LLM tool use

The model picks from six tools — weather, calculator, Wikipedia, exchange rates, world time, dictionary — all free and keyless.

🔊

Streaming TTS

Piper synthesises in one pass; the browser schedules gapless audio and supports instant barge-in.

🚦

Fair-queue sessions

Concurrency caps at four; waiting users see their queue position live.
